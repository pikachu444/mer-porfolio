# Google Gemini Gems — 메르AI 페르소나 설정 가이드

## 필요한 것

- Gemini Advanced 구독 ($20/월, 이미 있음) — Gems 기능은 Advanced 전용
- 설정 시간: 약 3분 (GPTs보다 훨씬 간단)

---

## 설정 순서

### 1단계 — Gems 생성 페이지 열기

방법 A (직접):
https://gemini.google.com/gems/create

방법 B (메뉴):
1. https://gemini.google.com 접속
2. 왼쪽 사이드바 → **"Gems"** → **"New gem"**

---

### 2단계 — Gem 기본 정보 입력

| 항목 | 입력값 |
|------|--------|
| **Name** | `메르AI` |
| **Description (선택)** | `메르 블로그 기반 한국·미국 주식 포트폴리오 분석가` |

---

### 3단계 — Instructions 입력 (핵심)

`gem_instructions.md` 파일의 **코드블록 안 내용 전체**를 복사해서
**Instructions** 텍스트 박스에 붙여넣기.

> Gemini Gems는 Instructions 하나만 입력하면 끝. GPTs처럼 별도 설정이 없음.

---

### 4단계 — 저장

**"Save"** 버튼 클릭 → 완료.

저장된 Gem은 왼쪽 사이드바 **"Gems"** 섹션에 표시됨.

---

## 사용 방법

### 방법 A — 자동 검색 요청

```
최근 2주간 메르 블로그 글 찾아서 포트폴리오 분석해줘
```
→ Gemini가 Google 검색으로 blog.naver.com/ranto28 최근 글을 찾아 분석

### 방법 B — 글 직접 붙여넣기

```
아래 메르 블로그 글들을 분석해서 포트폴리오 추천해줘:

[메르 블로그에서 복사한 글 내용]
```

### 방법 C — 자동화 파이프라인 결과물 활용

GitHub Actions로 생성된 리포트를 붙여넣고 추가 질문:
```
이번 포트폴리오에서 국내주식만 골라서 비중 조정해줘
저번 대비 뭐가 바뀐 거야?
조선업 관련 종목 더 자세히 설명해줘
```

## GPTs vs Gems 비교

| 항목 | ChatGPT GPTs | Gemini Gems |
|------|-------------|-------------|
| 설정 복잡도 | 중간 | 쉬움 |
| Web Search | 별도 설정 필요 | ✅ 기본 내장 |
| 한국어 품질 | 상 | 상 |
| 금융 분석 품질 | 상 | 상 |
| 대화 흐름 | 자연스러움 | 자연스러움 |
| Knowledge 파일 추가 | ✅ 가능 | ❌ 미지원 |
| 공유 | URL 공유 가능 | 본인만 사용 |

→ **평상시 채팅**: Gems가 더 간편 (구글 검색 자동 연동)
→ **정밀 제어 필요 시**: GPTs (Knowledge 파일, Actions 등 옵션 많음)

---

## 팁

- Gem에서 대화할 때 매번 새 대화를 시작하면 컨텍스트 오염 없이 분석 가능
- "저번 포트폴리오랑 비교해줘"가 필요하면 이전 리포트를 같이 붙여넣기
- Gemini는 Google 검색을 바로 쓸 수 있어서 "오늘 메르 글 뭐 올라왔어?"가 바로 됨
- 분석 깊이를 높이려면 "Deep Research 모드로 분석해줘"라고 추가하면 됨 (Gemini Advanced 전용)
