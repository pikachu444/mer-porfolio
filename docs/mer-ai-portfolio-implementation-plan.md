# 메르AI 포트폴리오 구현 기준

이 프로젝트는 메르 블로그 글을 수집해 LLM으로 요약·분석하고, 사용자가 살펴볼 종목 또는 섹터 ETF와 그 근거를 Telegram 및 HTML에 제공한다.

## 판단과 비중

- LLM은 원문 요약, 투자 인사이트, 메르 직접 언급과 AI 추론의 구분, 종목별 근거·위험·무효화 조건을 작성한다.
- `proposed_weight`는 기존 판단 흐름에서 만들어진 제안값을 사용한다.
- 런타임은 개별주 10%, 섹터·산업 ETF 30% 상한만 적용한다.
- 목표비중 합계가 100%를 넘을 때만 비례 축소한다. 남는 비중은 현금이다.
- 점수, 슬리브, 변동성 기반 배분, 최소 현금 규칙, 시장 베타 자동 편입은 사용하지 않는다.

## 출력

- Telegram은 글 요약, 인사이트, 전 보유 종목의 실제/목표비중, 오늘의 변경, 현금, 상세 HTML 링크를 짧게 제공한다.
- HTML은 표 중심으로 보유 종목과 오늘의 변경을 분리하고, 상세 행에 원문·근거·위험을 제공한다.
- 사용자 화면에는 validator, schema, provenance 등 내부 용어를 노출하지 않는다.
