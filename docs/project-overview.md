# 메르AI 포트폴리오 프로젝트 개요

## 목적

이 프로젝트는 메르 네이버 블로그 글을 수집해 모델 포트폴리오를 자동으로 갱신하고,
투자자가 Telegram 메시지와 HTML 대시보드에서 같은 내용을 확인할 수 있게 하는 시스템이다.

이 시스템은 메르 블로거의 실제 계좌를 복제하지 않는다. 블로그 글에 나타난 직접 판단과
AI의 해석을 구분해 만든 참고용 모델 포트폴리오다.

## 투자자에게 보이는 결과물

| 결과물 | 위치 | 기준 자료 |
|---|---|---|
| Telegram 메시지 | Telegram 봇 | 현재 모델 포트폴리오 상태 |
| HTML 대시보드 | `output/dashboard.html` | 현재 모델 포트폴리오 상태 |
| Markdown 보고서 | `output/report_YYYYMMDD.md` | 현재 모델 포트폴리오 상태 |
| Telegram 차트 이미지 | `output/chart_latest.png` | 현재 모델 포트폴리오 상태 |
| 수익률 표와 흐름 | HTML, Telegram | 현재 모델 포트폴리오 상태 + 수익률 계산 자료 |

사용자 출력의 기준은 `output/portfolio_state.json`에 저장된 현재 모델 포트폴리오 상태다.
`latest.md`는 사용자 출력 기준으로 사용하지 않는다.
보고서 기준일과 파일명은 한국시간(`Asia/Seoul`) 기준으로 계산한다. GitHub Actions 실행 환경의
UTC 날짜가 아니라 투자자가 메시지를 받는 한국 날짜를 사용한다.

## 핵심 원칙

- 메르의 직접 판단과 AI의 추론을 반드시 구분한다.
- AI의 추론을 메르의 직접 추천처럼 표시하지 않는다.
- 모델 포트폴리오 편입과 메르의 실제 보유를 혼동하지 않는다.
- 종목 변경은 근거 글, URL, 판단일을 추적할 수 있어야 한다.
- 원문 글을 특정할 수 없는 과거 보강 근거는 원문 근거처럼 표시하지 않고 과거 보고서 근거로
  구분한다.
- 새로운 근거 없이 판단과 목표 비중을 임의로 바꾸지 않는다.
- 현금성/방어성 비중은 단순 잔여값이 아니라 리스크 관리 요소로 본다.
- 기본 방어 기준은 현금성 20%이며, 큰 이벤트나 시장 리스크가 커진 구간에서는 이보다 높은
  현금성 비중을 제안할 수 있다.
- 기존 상태 마이그레이션이나 `미분류` 보유 종목은 신규 추천이 아니라 재검증 필요 포지션으로
  표시한다.
- AI 판단 포지션이라도 포트폴리오 역할(`allocation_role`)이 없는 과거 상태 항목은 추천이 아니라
  재검증 필요 포지션으로 표시한다.
- 수익률 계산 자료에 종목이 빠져도 현재 모델 포트폴리오에서 종목을 숨기지 않는다.
  이 경우 수익률은 `집계 전`으로 표시한다.
- 현재 모델 포트폴리오에 있는 종목은 종료 포지션에 동시에 남길 수 없다. 코드 오기나 과거 기록
  때문에 충돌하면 원천 기록을 정리한다.

## 분석 보류 정책

신규 글 요약이나 LLM 투자 판단이 한도 초과, 일시 장애, 응답 형식 오류로 완료되지 않을 수 있다.
이때 새 투자 판단을 임의로 만들지 않는다.

대신 현재 포트폴리오 상태를 유지하고 오늘 날짜 보고서, HTML, Telegram 메시지를 생성한다.
사용자 출력에는 분석 보류 사유와 보류된 글 제목, URL을 표시한다. Telegram은 최대 3건까지
짧게 보여 주고, HTML과 Markdown 보고서는 제목, URL, 날짜, 실패 사유를 표로 남긴다. 중요한
글이 조용히 제외된 것처럼 보이면 안 된다.

1차 포트폴리오 판단은 Gemini Pro 전용이다. Gemini Pro가 서버 혼잡으로 응답하지 않으면 5분
간격으로 5회 더 재시도하고, 그래도 실패하면 Flash로 투자 판단을 대신 만들지 않는다. 이 경우
사용자 출력에는 `Gemini Pro 서버 혼잡으로 리밸런싱 판단 보류. 포트폴리오 비중은 변경하지 않음`을
표시하고 기존 포트폴리오와 목표 비중을 유지한다.

## 리밸런싱 정책

- 매일 1회 신규 글을 수집한다.
- 신규 투자 관련 글이 있으면 포트폴리오 판단을 실행한다.
- 마지막 실제 리밸런싱 이후 14일이 지나고 그 기간에 신규 투자 관련 글이 있으면 누적 글로
  리밸런싱한다.
- 14일이 지났더라도 신규 투자 관련 글이 없으면 리밸런싱 날짜를 갱신하지 않고 다음 관련 글까지
  미룬다.
- 리밸런싱 때는 종목별 방향성뿐 아니라 주식 노출, 현금성 비중, 재검증 필요 포지션을 함께 본다.
- 신규 매수로 현금성 비중이 20% 아래로 내려가면 그 이유가 판단 결과에 명시되어야 한다.
