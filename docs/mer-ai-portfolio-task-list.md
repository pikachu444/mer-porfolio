## 31. GitHub Actions 전달·리밸런싱 운영 정상화

- [x] 정각 cron을 00:17 KST로 이동하고 동시 실행·30분 timeout·main 브랜치 운영 가드를 적용
- [x] 상태/보고서가 현재 Action의 영수증으로 검증되고 push된 뒤에만 Telegram 차트·구조화 요약을 발송
- [x] Telegram HTTP 200 외에 JSON `ok=true`와 `message_id`를 확인하고, 실패 시 Action·artifact에 명시적으로 남김
- [x] v2.0의 불완전한 리밸런싱 기준일을 폐기하고, v4 출처 요약 업그레이드가 끝날 때까지 부분 리밸런싱을 차단
- [x] Gemini/요약 보류 중에도 만료 Watchlist만 수명주기 규칙에 따라 archive

상세 운영 계약은 [Action 전달 신뢰성](./action-delivery-reliability.md)을 참고한다.
